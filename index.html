Sepsis-3 判定（任意）

論文の定義: 感染があり pSOFA が感染前から2点以上上昇 → sepsis。sepsis に加え、血管作動薬の持続投与と最大乳酸 >2 mmol/L (18 mg/dL) → septic shock。感染前の臓器障害が不明なら 0 とする。

採点表・注意点
  • 各臓器は24時間のうち最悪値で採点。未測定の項目は正常（0点）として扱う（論文の規定どおり）。
  • 呼吸: SpO₂/FiO₂ は SpO₂ ≤97% の値のみ使用。3・4点は呼吸補助ありの場合のみ付く（補助なしでは最大2点）。「呼吸補助」の具体的な範囲は論文に定義がなく、施設での判断に委ねられる。
  • 循環: MAP は0・1点の判定にのみ使用、2〜4点は血管作動薬の用量で判定（最大持続投与量、1時間以上の投与）。
  • 神経: 小児用GCSを使用。
  • 18歳超（216か月超）の閾値は成人SOFAと同一。
  • 表記の重なりの扱い: 論文 Table 1 では SpO₂/FiO₂ の2点が「221–264」と1点の「264–291」と重複し、ビリルビンの4点は「>12.0」で12.0ちょうどの区分が空く。本ツールでは SpO₂/FiO₂ を 221以上264未満 → 2点、ビリルビンを 12.0以上 → 4点として扱う。クレアチニンの区分間の隙間（例 0.8–0.9 と 1.0–1.1 の間）は、下限値を超えた最も高い点数に割り当てる。
  • 論文での位置づけ: 後ろ向き単一施設（PICU 8711 encounter）。最大pSOFAの院内死亡判別AUCは 0.94、最適カットオフは 8点超。日々の最大値に基づく結果で、単回の値から個別の死亡予測をするものではない。
  • 本ツールは臨床判断の補助です。診療上の判断は担当医が行ってください。
